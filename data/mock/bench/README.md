# Benchmark fixtures

Large synthetic CSV fixtures belong here and are intentionally ignored by Git.

- `generated/` is the shared Ethereum-format account/Merkle fixture used by the NIZK benchmark.
- `smt-persisted/` is generated by `scripts/initialize_smt_benchmark_data.sh`. It reuses the
  same accounts, signatures, balance proofs, deltas and insert candidate, and stores one verified
  Poseidon SMT initialization state/proof per requested `n`.

The SMT state metadata is text, while leaves and non-default nodes are binary sidecars so large
states can be loaded without parsing million-entry CSV lines.
